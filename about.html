What I'm proud of

I'm proudest of two projects, because each taught me something different about how software gets built.

The Personal Finance Tracker, which I built in C with Nish Patel, taught me that working in a pair changes the whole process. The hardest part wasn't the code; it was deciding which features to build over others. You have to agree on those decisions before you code instead of just making them yourself.

Shelf-Wise, my store inventory app, taught me the other side: working alone on a full-stack application. I'm building it in phases to learn the full development process, from documentation and design through to a working product.
